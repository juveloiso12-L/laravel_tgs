d. Dasar Teori
Apa Itu Middleware di Laravel?, Middleware di Laravel adalah lapisan perantara
(interceptor) yang menangani permintaan HTTP sebelum mencapai controller atau
setelah respons dikirim ke klien. Middleware digunakan untuk memproses logika
tertentu seperti autentikasi, logging, CORS, validasi token, dan lainnya.
Middleware bisa digunakan untuk berbagai tujuan, seperti:
a) Memeriksa apakah pengguna telah login.
b) Mengecek peran atau izin pengguna.
c) Memfilter atau memodifikasi permintaan sebelum mencapai controller.
d) Menangani CORS (Cross-Origin Resource Sharing).
e) Melakukan logging terhadap permintaan HTTP.
2. Cara Kerja Middleware
Middleware bekerja seperti rantai (pipeline) yang mengelola request dan response.
Berikut adalah alur kerjanya:
a) Client mengirimkan permintaan HTTP ke server.
b) Middleware menangkap dan memproses permintaan.
c) Jika request valid, diteruskan ke controller.
d) Controller memproses request dan mengembalikan response.
e) Middleware kembali menangkap response sebelum dikirim ke client.
f) Client menerima response dari server.

1) Membuat Middleware di Laravel
Untuk membuat middleware baru, gunakan perintah Artisan:
php artisan make:middleware Admin
Perintah ini akan membuat file Admin.php di direktori app/Http/Middleware.
2) Struktur Middleware
Middleware yang baru dibuat akan terlihat seperti ini:
<?php
namespace App\Http\Middleware;
use Closure;
use Illuminate\Http\Request;
use Auth;
class Admin {
public function handle(Request $request, Closure $next){
if (Auth::check()){
if(Auth::user()->role == 'admin'){
return $next($request);
} else {
abort(403);
}
} else {
return redirect()->route('login');
}
}
}
● $request->age mengambil parameter age dari request.
● Jika umur kurang dari 18 tahun, permintaan ditolak dengan status 403
Forbidden.
● Jika memenuhi syarat, request diteruskan ke controller dengan
$next($request).

3) Mendaftarkan Middleware
Setelah middleware dibuat, pada Laravel 10 kita harus mendaftarkannya di file
app/Http/Kernel.php. Sedangkan Pada Laravel 11 & 12 kita harus mendaftarkannya
di file bootstrap/app.php.
a) Middleware Global
Jika ingin middleware berlaku untuk semua request, tambahkan di bagian $middleware
:
protected $middleware = [
\App\Http\Middleware\Admin::class,
];
b) Middleware Grup
Jika middleware hanya digunakan untuk grup tertentu (misalnya API atau web),
tambahkan di bagian $middlewareGroups:
protected $middlewareGroups = [
'web' => [
\App\Http\Middleware\Admin::class,
],
'api' => [
\App\Http\Middleware\Admin::class,
],
];
c) Middleware Route / Alias
Untuk middleware yang hanya digunakan pada route tertentu, daftarkan di
$routeMiddleware:
protected $routeMiddleware = [
'admin' => \App\Http\Middleware\Admin::class,
];
pada Laravel 11 & 12 middleware didaftarkan di ->withMiddleware()
$middleware->alias([
'admin' => Admin::class,
'petugas' => Petugas::class,
'siswa' => Siswa::class,
]);

4) Menggunakan Middleware pada Route
Setelah middleware terdaftar, kita bisa menggunakannya di route:
Route::get('/admin', function () {
return "Selamat datang!";
})->middleware('admin);
5) Middleware dengan Parameter
Middleware juga bisa menerima parameter, misalnya untuk membatasi akses
berdasarkan peran:
a) Membuat Middleware
public function handle(Request $request, Closure $next, $role)
{
if ($request->user()->role !== $role) {
return response()->json(['message' => 'Akses ditolak!'], 403);
}
return $next($request);
}
b) Menggunakannya di Route
Route::get('/admin', function () {
return "Halaman Admin";
})->middleware('cek.role:admin');
6) Middleware Terminate
Middleware bisa memiliki metode terminate() untuk menangani tugas setelah respons
dikirim ke klien. Contohnya untuk logging:
public function terminate($request, $response)
{
\Log::info('Request selesai', ['url' => $request->fullUrl()]);
}
Untuk menggunakan fitur ini, pastikan middleware terdaftar di Kernel.php.

Laravel Authentication adalah fitur bawaan Laravel yang digunakan untuk mengelola
proses autentikasi pengguna secara aman dan efisien. Laravel menyediakan sistem
autentikasi yang fleksibel dan mudah dikonfigurasi, mencakup login, registrasi, reset
password, dan manajemen sesi pengguna.
Dengan berbagai pilihan seperti Laravel Breeze, Jetstream, dan Sanctum, pengembang
dapat menyesuaikan autentikasi sesuai dengan kebutuhan proyek, baik itu aplikasi
berbasis web maupun API. Jika Anda ingin membangun sistem autentikasi Laravel
dengan cepat, gunakan Breeze atau Jetstream. Namun, jika Anda ingin
mengembangkan solusi khusus, gunakan pendekatan manual dengan Auth Facade atau
Sanctum untuk API.
1. Komponen Utama Laravel Authentication
Laravel Authentication terdiri dari beberapa komponen utama:
a) Guards
Guards adalah mekanisme yang digunakan untuk menentukan bagaimana pengguna
diautentikasi. Laravel menyediakan beberapa jenis guard:
1) Session Guard → Menggunakan sesi dan cookies untuk autentikasi (default).
2) Token Guard → Menggunakan token API untuk autentikasi (cocok untuk aplikasi
RESTful).
3) Sanctum & Passport → Digunakan untuk autentikasi API yang lebih kompleks.
Guards dikonfigurasi di dalam file config/auth.php:
'guards' => [
'web' => [
'driver' => 'session',
'provider' => 'users',
],
'api' => [
'driver' => 'token',
'provider' => 'users',
'hash' => false,
],
],
b) Providers

Providers menentukan bagaimana pengguna diambil dari database. Laravel secara
default menggunakan Eloquent ORM atau Query Builder. Contoh konfigurasi provider
di config/auth.php:
'providers' => [
'users' => [
'driver' => 'eloquent',

3. Recreating Logout Feature
Untuk membuat fitur logout secara manual, kita bisa menggunakan Auth Facade.
a) Menambahkan Logout di Controller
Buka atau buat file AuthController.php:
use Illuminate\Http\Request;
use Illuminate\Support\Facades\Auth;
class AuthController extends Controller {
public function logout(Request $request) {
Auth::logout(); // Logout user
$request->session()->invalidate(); // Hapus sesi
$request->session()->regenerateToken();
// Regenerasi CSRF token
return redirect('/'); // Redirect ke halaman utama
}
}
b) Menambahkan Rute Logout
Tambahkan rute di routes/web.php:
Route::post('/logout', [AuthController::class, 'logout'])->name('logout');
c) Menambahkan Tombol Logout di Blade
Tambahkan di layouts/app.blade.php:
<form action="{{ route('logout') }}" method="POST">
@csrf
<button type="submit">Logout</button>
</form>
Dengan ini, pengguna dapat logout dengan aman.

d. Dasar Teori
Laravel menyediakan mekanisme authorization yang fleksibel untuk mengontrol akses
pengguna ke berbagai bagian aplikasi. Otorisasi ini digunakan untuk memastikan bahwa
hanya pengguna yang memiliki hak tertentu yang dapat melakukan suatu tindakan.
Dalam Laravel, authorization dapat dikelola dengan gates dan policies.

f. Prosedur Kerja
1. Gates (Gerbang)
Gates adalah fungsi sederhana yang menentukan apakah pengguna memiliki izin untuk
melakukan tindakan tertentu. Gates biasanya didefinisikan dalam
App\Providers\AuthServiceProvider.
a) Cara Menggunakan Gates & Menentukan Gate
Tambahkan dalam AuthServiceProvider.php:
use Illuminate\Support\Facades\Gate;
use App\Models\User;
public function boot()
{
Gate::define('edit-post', function (User $user, $post) {
return $user->id === $post->user_id;
});
}

b) Menggunakan Gate dalam Controller
use Illuminate\Support\Facades\Gate;
public function update(Request $request, Post $post)
{
if (Gate::denies('edit-post', $post)) {
abort(403, 'Anda tidak memiliki izin untuk mengedit postingan ini.');
}
// Lanjutkan dengan update post...
}
c) Menggunakan Gate dalam Blade
@can('edit-post', $post)
<button>Edit</button>
@endcan
2. Policies (Kebijakan)
Policies adalah kelas khusus yang menangani logika otorisasi untuk model tertentu.
Biasanya digunakan untuk skenario yang lebih kompleks dibandingkan gates.
a) Membuat dan Menggunakan Policies
untuk Membuat Policy Jalankan perintah artisan:
php artisan make:policy PostPolicy
Ini akan menghasilkan file policy di app/Policies/PostPolicy.php.
b) Mendefinisikan Otorisasi dalam Policy
Buka PostPolicy.php dan tambahkan metode otorisasi:
D4 – TEKNIK INFORMATIKA
BKPM – WORKSHOP SISTEM INFORMASI WEB FRAMEWORK
namespace App\Policies;
use App\Models\User;
use App\Models\Post;
class PostPolicy
{
public function update(User $user, Post $post)
{
return $user->id === $post->user_id;
}
}
c) Mendaftarkan Policy di AuthServiceProvider
use App\Models\Post;
use App\Policies\PostPolicy;
protected $policies = [
Post::class => PostPolicy::class,
];
d) Menggunakan Policy dalam Controller
public function update(Request $request, Post $post)
{
$this->authorize('update', $post);
// Jika lolos, lanjutkan update
}
e) Menggunakan Policy dalam Blade
@can('update', $post)
<button>Edit</button>
@endcan

3. Middleware Authorization
Selain menggunakan gates dan policies, Laravel juga menyediakan middleware can
untuk mengontrol akses dalam route.
a) Menentukan Middleware dalam Route
Route::get('/post/{post}/edit', [PostController::class, 'edit'])
->middleware('can:update,post');
b) Middleware dalam Controller
public function __construct()
{
$this->middleware('can:update,post')->only('edit', 'update');
}
